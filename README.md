# SOPRAVVIVI

App web di sopravvivenza **pensata per funzionare senza Internet**.

Non sostituisce il 112, GeoResQ, un corso BLSD o il buon senso. È un manuale tascabile da avere sul telefono quando non c'è campo.

## Cosa c'è dentro

- Primo soccorso: RCP, emorragia, soffocamento, ipotermia, colpo di calore, fratture, ustioni, morsi
- Acqua, fuoco, riparo, cibo (con i limiti seri del foraging)
- Orientamento e segnali di disagio
- Scenari Italia: montagna, bosco, mare/alluvione, terremoto, blackout, auto
- GPS e bussola del telefono (senza rete)
- Checklist kit + scheda medica in locale
- PWA installabile sulla Home

## Come usarla

1. Apri il sito **una volta con rete**
2. Installa: Chrome → Installa app / iPhone → Condividi → Aggiungi alla Home
3. Riapri l'icona in modalità aereo e controlla che le guide ci siano

## Sviluppo

Sito statico. Qualsiasi hosting va bene (Vercel, GitHub Pages, cartella sul telefono).
